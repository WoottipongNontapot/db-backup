DB Backup

A private backup utility operated by Woottipong Nontapot for authorized database administration.

What this application does

DB Backup uses rclone to upload completed SQL Server backup files from an administrator-managed Windows server to a designated Google Drive folder. Scheduled cleanup is intended to remove backup files older than seven days after a successful upload.

Google Drive access

The intended configuration requests the drive.file permission to create, read, update and delete files and folders created by this application. Access is authorized by the Google account owner. This website does not provide a login or upload service and does not host database backups.

This utility is for the operator and authorized administrators; it is not offered as a public backup service.
