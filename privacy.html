Privacy Policy

Effective date: 26 October 2026

This policy describes the intended operation of DB Backup, operated by Woottipong Nontapot, and its use of Google user data.

Data accessed

With the account owner's authorization, the utility accesses backup file content and metadata, including file names, sizes, modification times and identifiers, within files and folders accessible under the configured Google Drive permission. It uses OAuth tokens to maintain authorized access.

Purpose and use

Data is used only to upload and manage authorized SQL Server backup files, check transfers and perform scheduled retention cleanup. Backup files can contain personal or confidential database records. The operator is responsible for having permission to back up those records.

Storage and protection

Backup files are stored on the source server and in the designated Google Drive account. OAuth credentials and tokens are stored in the server's rclone configuration. Operational logs may contain file names and transfer details. Access to server files, configuration and the Drive folder should be restricted to authorized administrators. This public website does not collect or store backups, passwords or OAuth tokens.

Sharing

Google processes files as the selected storage provider, and GitHub hosts this informational website. The utility does not sell Google user data, use it for advertising, or use it to train AI models. Backup data is not intentionally shared with unrelated third parties. Authorized administrators and any people granted access to the Drive folder may access it.

Retention and deletion

The intended Drive retention period is seven days, enforced by an administrator-configured scheduled job. Cleanup depends on successful execution and may be delayed by failures. Local backup and log retention are managed separately. Files moved to Drive Trash remain subject to Google's trash policy unless permanently deleted.

Control and revocation

The account owner can revoke the application's access in Google Account settings under third-party connections. Revoking access stops future authorized API operations but does not automatically delete existing backups. The owner can delete existing files in Google Drive or contact the operator for assistance.

Google API data use

DB Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
